Romaji Overlay for Windows
--------------------------
Press Ctrl+Alt+R in your game: Japanese on the screen turns into romaji, drawn over the text.
Press again (or wait) to clear it. The window keeps a history of what it read.

One-time setup: Windows needs its Japanese OCR pack.
Settings > Time & language > Language & region > Add a language > Japanese,
and keep "Optical character recognition" ticked.

Game tip: use Windowed or Borderless mode so the overlay can show above the game.
It only takes a screenshot and shows its own click-through window. It never touches game files or memory.
